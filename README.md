# Intelligent Student Assignment Evaluation Assistant
*A Natural Language Processing & Computer Vision application for automated preliminary evaluation of student answer sheets.*

**GitHub Repository:** [https://github.com/Gowda1007/Assignment-Evaluator.git](https://github.com/Gowda1007/Assignment-Evaluator.git)

---

## 📌 Overview

Evaluating student assignments manually is a tedious, time-consuming challenge for academic faculty. This application automates the assessment pipeline by:
1. **Reading printed student answer-sheet documents** using Optical Character Recognition (**EasyOCR**) supporting both **Image (PNG, JPG) and PDF format**.
2. **Parsing structured metadata** (Student ID, Question Number, Question text, and written response) with OCR error-tolerance normalization (e.g. `O` ↔ `0`, `l` ↔ `1`).
3. **Retrieving reference answers & marking rubrics** from faculty curriculum files (`questions.csv` & `marking_rubric.csv`).
4. **NLP Preprocessing**: Tokenization, lowercasing, punctuation stripping, and stop-word filtering.
5. **4-Layer Explainable Concept Matching**:
   - **Layer 1: Exact Word-Boundary Matching** (`\bconcept\b`)
   - **Layer 2: Stemming / Morphological Normalization** (NLTK `PorterStemmer` — handles inflectional variants like `identifies` vs `identifying`)
   - **Layer 3: WordNet Synset Mapping** (NLTK `WordNet` — handles semantic equivalents like `splitting` ↔ `divides`)
   - **Layer 4: Fuzzy String Matching** (`fuzzywuzzy.fuzz.partial_ratio`)
6. **Relevance Gate**: Capping marks at `0` for off-topic submissions (such as the tricky `MCA003 Q1` case).
7. **Humanized Feedback & Faculty Review**: Generating constructive suggestions and providing an interactive panel for instructors to verify, override marks, and export CSV logs.
8. **Submission Report Ready**: Includes `Project_Evaluation_Report.docx` and `PROJECT_REPORT.md` with execution screenshot placeholders.

## 🏗️ Architecture

```
Student Answer Sheet Image (.png)
               │
               ▼
   [ Step 1 & 2: EasyOCR Engine ]
               │
               ├── Student ID (e.g. MCA001)
               ├── Question ID (e.g. Q1)
               └── Student Answer Text
               │
               ▼
   [ Step 3: Question & Rubric Retrieval ]
               ├── Faculty Reference Answer
               └── 5 Rubric Concept Points (1 mark each)
               │
               ▼
   [ Step 4: NLP Preprocessing ]
               ├── Lowercase & Punctuation Strip
               ├── Word Tokenization
               └── Stopword Removal & Keyword Extraction
               │
               ▼
   [ Step 5 & 6: 4-Layer Rubric Concept Matcher ]
               ├── Layer 1: Exact Boundary Match
               ├── Layer 2: Porter Stemming
               ├── Layer 3: WordNet Synset Equivalences
               └── Layer 4: Fuzzy Partial Ratio
               │
               ▼
   [ Relevance Gate ] ────── Capping to 0 if off-topic
               │
               ▼
   [ Step 7 & 8: Preliminary Marks & Faculty Review ]
               ├── Preliminary Marks (out of 5)
               ├── Covered vs Missing Concept Breakdown
               ├── Actionable Improvement Feedback
               └── Faculty Override & CSV Export
```

## 📊 Benchmark Validation Results (All 24 Images)

The complete pipeline was evaluated end-to-end against the ground-truth benchmark (`student_answers.csv`):

| Metric | Benchmark Result | Faculty Target / Standard |
|---|---|---|
| **Total Test Images** | **24** (3 students × 8 questions) | 24 |
| **Average OCR Word Accuracy** | **86.0%** | > 80% |
| **Category Accuracy** | **91.7%** (22 / 24 correct) | > 80% |
| **Marks MAE (Mean Absolute Error)** | **0.62 marks** out of 5 | < 1.0 mark |
| **Within ±1 Mark** | **87.5%** | > 75% |
| **Irrelevant Answer Detection (MCA003)** | **100% Precision & Recall** (0 / 5) | 100% |

> [!NOTE]
> All marks generated by the assistant are explicitly labelled as **preliminary** in accordance with academic guidelines. The faculty member makes the final evaluation decision.

## 🚀 How to Run the Application

### 1. Prerequisites
Ensure you have Python 3.10+ (or your active Conda environment) ready.

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Launch the Web Application
```bash
streamlit run app.py
```
Open your browser at `http://localhost:8501`.

### 4. Run CLI Validation Test
To verify the full 24-image benchmark in terminal:
```bash
python validate.py
```

